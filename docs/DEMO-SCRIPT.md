# LearnLens — 3-minute demonstration plan

**Team:** HJKS Squad · **Event:** Code Kernel '26 | Decode · **Duration:** 3:00

This is the recording script and storyboard. Record the running prototype and narration; the repository does not contain a recorded video yet.

| Time | Screen / action | Narration |
|---|---|---|
| 0:00–0:20 | Landing page | "In one classroom, every student may have a different learning pace. But not every student has a personal smartphone or tablet. LearnLens is designed around that reality." |
| 0:20–0:45 | Show class/topic selectors and shared-device note | "Instead of requiring one device per learner, LearnLens runs on a shared classroom computer or teacher-led screen. Students can take turns or work in small groups." |
| 0:45–1:25 | Choose Class 8, Mathematics, Fractions; complete quiz | "A learner chooses a topic and answers a short diagnostic. Each response gives immediate feedback and an explanation, not just a right-or-wrong result." |
| 1:25–1:55 | Show learning recommendation | "The prototype recommends a next step: guided revision, standard practice, or a challenge, depending on the result." |
| 1:55–2:25 | Teacher view | "The teacher view demonstrates how class patterns could guide support. These are sample values, not real student records. The teacher remains in control." |
| 2:25–2:45 | Show architecture and repository | "Technically, this is a lightweight browser application with a question bank, answer evaluator, and transparent recommendation rules." |
| 2:45–3:00 | Return to landing page | "LearnLens is our step toward adaptive learning that includes students regardless of device ownership. We are HJKS Squad. Thank you." |

## Recording checklist
- Record on laptop/desktop at 1920×1080 if possible.
- Use a clean browser window and hide personal notifications.
- Show a complete quiz attempt and the result recommendation.
- Pause briefly on the teacher view and architecture.
- Record narration in a quiet room and align it to the timeline.
- Export MP4 (H.264), 1080p, approximately three minutes.
- Do not show real student names or private information.
